Introducción a datos MNIST: El Hola Mundo del Machine Learning
EL MNIST es la prueba obligatoria que deben pasar los algoritmos para demostrar que tiene la capacidad para distinguir valores y características.

Clasificación Binaria: No sé.

Matriz de Confusión: Equivalente a un consultor que busca errores.
Se firma una matriz donde se organizan los resultados de las pruebas entre si el algoritmo respondio correctamente, respondio parcialmente bien, o se equivoco. AL organizar la informacion de esta forma, podemos identificar las fortalezas y debilidades del algoritmo

Precisión y ROC: Precisión: Cuantas veces el algoritmo respondio bien. Exhautividad: Porcentaje de datos presentados al algoritmo que se adivinaron correctamente. NO SE PUEDE TENER UN ALGORITMO CAPAZ DE TENER UN ALGORITMO CON PRECISIÓN Y EXHAUTIVIDA TOTAL.

Clasificación Multiclase: Hacemos varias matrices con diferentes enfoques. Una a nivel general, otra dedicada a errores, otra a fortalezas. Esto asegura recisión en la información de los errores ;)
